# Football Live Score

A WPF desktop app that shows live Premier League scores, fixtures, results and the league table.

<img width="1851" height="994" alt="image" src="https://github.com/user-attachments/assets/506f1b32-558d-403e-826a-524a9921259c" />


## Features
- Live match scores
- Fixtures and results
- Premier League table
- Simple tabbed layout

## Built With
- C#
- WPF and XAML
- REST API
- JSON

## How to Run
1. Clone the repo
2. Open `Project1.sln` in Visual Studio
3. Build and run the project
